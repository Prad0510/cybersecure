# Platform Blocking & Restricting Guide

Step-by-step instructions for blocking hostile or harassing accounts across major platforms.

## 1. Instagram
- **Direct Block**: Navigate to the offending profile -> Tap the three dots (`...`) in the upper-right corner -> Select `Block` -> Choose "Block [username] and other accounts they may have or create".
- **Restrict Mode**: If you want to silently limit interaction without notifying them: Tap three dots -> Select `Restrict`. Their comments will only be visible to them unless approved, and their DMs will move to Message Requests.
- **Hidden Words**: Go to Settings -> Privacy -> Hidden Words -> Turn on "Hide offensive comments" and add custom keywords.

## 2. WhatsApp
- **Individual Contact**: Open chat -> Tap contact name / header -> Scroll down and tap `Block [Contact Name]` -> Confirm `Block`.
- **Unknown Number**: In the top banner of a new chat from an unknown sender, tap `Block` or `Report & Block`.
- **Group Settings**: Prevent unknown users from adding you to groups: Settings -> Privacy -> Groups -> Select `My Contacts` or `My Contacts Except...`.

## 3. X (formerly Twitter)
- Tap the three dots on the user profile or tweet -> Select `Block @username`.
- Use `Mute conversation` to stop receiving notifications from hostile reply chains.

## 4. Discord
- Right-click username -> Select `Block`.
- In User Settings -> Privacy & Safety -> Disable "Allow direct messages from server members" for high-risk servers.
